# bm25.test.ts — BM25 Search & Confidence Gate Tests

**Path:** `packages/cortex-core/src/retrieval/__tests__/bm25.test.ts`

## What it tests

10 test cases covering BM25 search accuracy and confidence gate behavior:

- Search by simple name (`OrderService`)
- Search by partial name (`Order`)
- Search by javadoc content (finds symbols via documentation)
- Search with dotted qualified names (`com.example.OrderService`)
- Kind filter (`class` vs `method`)
- SpringRole filter (`SERVICE`, `REPOSITORY`)
- Empty result handling
- Project isolation (wrong project ID returns nothing)
- Gate pass (high-confidence result passes through)
- Gate fail (low-confidence result is blocked)
