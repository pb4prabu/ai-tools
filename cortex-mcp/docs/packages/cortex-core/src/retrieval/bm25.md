# bm25.ts — BM25 Full-Text Search

**Path:** `packages/cortex-core/src/retrieval/bm25.ts`

## What it does

Performs keyword search against the SQLite FTS5 index using BM25 scoring. This is the fastest and cheapest search mode — pure SQL, no external models.

## How it works

1. **Sanitize query** — Splits CamelCase (`OrderService` → `Order Service`), replaces dots with spaces, strips special characters
2. **Build SQL** — Queries `symbols_fts` FTS5 virtual table with optional filters (kind, springRole, hexRole, filePattern)
3. **Return ranked results** — Sorted by BM25 relevance score (higher = better match)

## Query sanitization example

```
Input:  "OrderService.createOrder"
Step 1: "Order Service.create Order"  (CamelCase split)
Step 2: "Order Service create Order"  (dots → spaces)
Step 3: "Order Service create Order"  (strip special chars)
```

## Filters

All filters are optional and combined with `AND`:
- `kind` — `class`, `method`, `interface`, `field`, etc.
- `springRole` — `REST_CONTROLLER`, `SERVICE`, `REPOSITORY`, etc.
- `hexRole` — `USE_CASE_HANDLER`, `DOMAIN_ENTITY`, `ADAPTER`, etc.
- `filePattern` — SQL `LIKE` pattern on file path

## Key export

```typescript
searchBM25(db, query, projectId, filters?, limit?) → BM25Result[]
```

## Strengths & weaknesses

- **Fast:** ~1ms per query, pure SQL
- **Token-efficient:** Returns only matching symbols (~10-100 tokens vs 5000+ for reading files)
- **Weakness:** Can't handle natural language. "how does auth work?" won't match `AuthController` because there's no keyword overlap
