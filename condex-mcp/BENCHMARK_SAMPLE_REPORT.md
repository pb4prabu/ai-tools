## Observations

- **BM25 excels** at exact name lookups and role-filtered searches (83-87% savings)
- **Vector search** handles natural language and cross-cutting queries well (80-85% savings)
- **Direct lookups** (outline, file outline) are the most token-efficient (69-86% savings)
- **Worst case** was file outline (69%) — still significant savings vs reading the full file
- **Best case** was hex role filtering (87%) — Condex returned 21 handlers in one query vs reading 21 files
- **Zero misses** — all 12 queries returned relevant results (100% hit rate on this codebase)
